# DEMO SCRIPT

**smartci: predicting CI test failures to run the right tests first**

Generated by `python -m stp.reports.presentation_md`. Order: ML Lab, Real PRs, GitHub PR, honest verdict.

## The 60-second pitch

> "When programmers change code, a server re-runs thousands of tests in a fixed order, often for hours. We trained models on 108,000 real CI runs to predict which tests will fail for a change, and run those first; nothing is skipped. On big projects with long history, like Kafka and TVM, the model beats the best simple rule. On a small Python library a simple rule, 'run the tests of the files you changed', is just as good, and for tests failing for the first time 'fastest test first' wins. Our tool measures which order works on your code and recommends it."
